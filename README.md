# Roma Nodes

## Meshroom Nodes

### RomaPrepare
Compute once per image the resized inputs and DINO features needed by ROMA matching and store them in an archive, so that they are not recomputed for every pair. Uses GPU processing.

### RomaMatcher
Compute ROMA warp and confidence images on a list of image pairs, using the archive of RomaPrepare. Each unordered pair is matched once for both directions, and the refinement reuses per-image features cached on the GPU. Writes warp, confidence and covariance archives. On Ampere and newer GPUs the refiners are compiled with torch.compile. Uses GPU processing.

### RomaFeaturesMatcher
Use the Roma warp images to restrict the region used to match features. A region will only be matched to features in the other image given the warp image coordinates.

### RomaMatchingFilter
Assumes a set of features have already been matched photometrically. Confirms the match using Roma.

### RomaSampler
Sample the dense ROMA matches to generate features/matches used by SFM. This is an intermediate node which must be followed by RomaReducer.

### RomaReducer
Merges multiple output files from the parallelized RomaSampler into a single result.

### RomaConsistency
Update confidence map based on consistency. Checks consistency per triplet (reference frame + two consecutive frames) and validates that cumulated motion is consistent.

### MatchMasking
Mask the confidence images generated by RomaMatcher given the associated masks of the reference and matched images.

### TracksMasker
Create a mask given tracks. For each track observation, adds a circle of specified radius to avoid adding features close to existing positions.

### AllListing
Generate an image pair list to match later. For all keyframes, matches with all the frames.

### StarListing
Generate an image pair list to match later. For all keyframes, matches with previous and next frames within a specified radius.

### GlobalTracks
Merges existing tracks into the SFM data.

### TripletFilter
For each reference view, filter all tracks using triplet consistency.
